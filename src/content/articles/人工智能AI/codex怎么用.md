## 快速结论

Codex 是 OpenAI 面向写代码、改代码、审查代码和运行开发任务的 AI 编程助手。你可以把它理解成“能进入项目、读文件、改文件、跑命令、解释结果的 ChatGPT 编程模式”。

想要长期稳定使用 Codex，重点不是找一次性账号，而是准备一套属于自己的账号体系：

1. 一个自己控制的 Google 邮箱，用来注册和登录 ChatGPT、GitHub、开发工具等海外网站。
2. 一个能长期保留的手机号或 eSIM 方案，用于账号安全、恢复和可能出现的验证码。
3. 一个自己的 ChatGPT 账号，建议开启多因素验证。
4. 根据使用强度选择 ChatGPT Plus、Pro 或 API key；新手通常先从 Plus 开始更顺。
5. 准备稳定网络环境，再用 Codex App、Codex CLI、IDE 插件或 Codex Web 开始工作。

如果你是第一次搜“codex怎么用”或“codex是什么”，先记住一句话：**Codex 不是普通聊天机器人，它更像一个能帮你完成软件开发任务的 AI agent。**

## 一、Codex是什么？

Codex 是 OpenAI 的编程 agent，主要帮助用户完成代码相关工作，包括：

| 场景 | Codex可以做什么 |
|---|---|
| 写代码 | 根据需求新增页面、组件、脚本、接口或测试 |
| 改代码 | 阅读项目结构后按现有风格修改文件 |
| 查问题 | 分析报错、定位 bug、解释日志 |
| 做 review | 检查 PR、指出风险、补测试建议 |
| 跑验证 | 在授权范围内运行构建、测试、lint 等命令 |
| 写文档 | 根据代码生成 README、使用说明和变更说明 |

普通 ChatGPT 更像“问答助手”；Codex 更像“开发协作者”。你给它一个目标，它会围绕项目上下文持续读文件、改文件和验证结果。

## 二、Codex怎么用？新手完整流程

### 第一步：准备一个长期可用的 Google 邮箱

Google 邮箱是很多海外网站的通用入口。ChatGPT、GitHub、Notion、Figma、Vercel、Cursor、Replit 等工具都常见 Google 一键登录，体验类似国内网站使用微信一键登录。

建议你优先自己注册和保管 Google 账号：

- 使用真实、长期可控的恢复邮箱和手机号
- 开启两步验证
- 保存恢复代码
- 不要多人共用同一个账号
- 不要把验证码、恢复邮箱、浏览器登录态交给陌生人

> 不建议购买来路不明的 Google 账号。账号转卖、共享验证码、共享恢复邮箱都可能带来封号、被找回、隐私泄露和支付风险。如果确实使用第三方服务，务必确认服务合规、账号最终完全归你控制，并保留自己的恢复方式。

### 第二步：准备可长期保留的手机号或 eSIM

ChatGPT 或相关服务在不同时间、不同地区、不同风控状态下，可能会要求邮箱验证、手机号验证、多因素验证或其他安全验证。是否需要 WhatsApp、短信或手机号，以页面实时提示为准。

更稳妥的原则是：**不要依赖一次性接码平台，尽量准备一个自己能长期保留的号码。**

如果你考虑国外手机号或 eSIM，可以按下面思路准备：

| 方案 | 适合人群 | 注意事项 |
|---|---|---|
| eSIM 手机卡 | 想长期保留海外号码的人 | 需要手机支持写入 eSIM，流量和续费规则要看清 |
| Google Pixel 手机 | 想搭配 Google 生态的人 | Pixel 5 及以上机型通常更适合折腾 Google 生态，购买二手机要查锁和成色 |
| 支持 eSIM 的 iPhone | iPhone 用户 | 不同地区版本的 iPhone 对 eSIM 支持不同，下单前要确认 |
| 自有实体海外 SIM | 有海外亲友或长期海外需求的人 | 成本和维护难度更高，但归属更清晰 |

ESIMPlus 可以作为一个可了解的 eSIM 方案，但下单前要自己核对官网、套餐地区、号码保留规则、充值方式、是否支持目标平台验证码，以及手机是否支持 eSIM。eSIM 流量通常不便宜，适合少量验证、保号和轻量使用；如果流量快用完，需要按服务商规则续费或购买新套餐。

如果使用第三方 eSIM 服务，优先查看服务商官方页面、退款规则、号码保留规则和目标平台验证码支持情况，不建议只看推广页下单。

### 第三步：注册并保护自己的 ChatGPT 账号

注册 ChatGPT 时，可以使用 Google 邮箱登录。长期使用时，重点是账号归属和安全：

1. 用自己的邮箱注册。
2. 绑定自己的恢复方式。
3. 开启多因素验证。
4. 不要购买共享 ChatGPT 账号。
5. 不要把登录态、Cookie、恢复代码发给别人。
6. 使用 Codex CLI 或桌面端时，保护好本机登录凭据。

OpenAI 官方文档提到，Codex 可以通过 ChatGPT 账号登录；Codex 云端能力通常需要 ChatGPT 登录。CLI、IDE 插件等场景也可能支持 API key 或其他配置，具体以当时官方文档为准。

## 三、需要 ChatGPT Plus 吗？

截至 2026 年 6 月，OpenAI 帮助中心说明 Codex 已包含在多个 ChatGPT 计划中，包括 Free、Go、Plus、Pro、Business、Edu 和 Enterprise，不同计划的额度和能力会不同。

所以更准确的说法是：

- 体验 Codex：不一定只有 Plus 才能开始。
- 想更流畅、更高额度、更适合持续写代码：Plus 或更高计划更合适。
- 团队、企业、合规和更高额度：看 Business、Edu、Enterprise 或 Codex credit 相关方案。
- 开发者/API 场景：也可以根据需求配置 OpenAI API key。

ChatGPT Plus 官方入口：[chatgpt.com/explore/plus](https://chatgpt.com/explore/plus?utm_internal_source=openai_developers_codex)

建议优先通过官方入口订阅或查看方案说明，避免购买共享会员、代充会员或来源不明账号。

## 四、如何开始使用 Codex？

### 方式一：Codex App

适合不想折腾命令行的新手。打开 Codex App，使用 ChatGPT 账号登录，选择项目目录，然后直接输入任务。

示例提示词：

```text
请先阅读这个项目结构，告诉我它是什么技术栈、入口文件在哪里、如何本地运行。
```

```text
帮我新增一个文章详情页，风格保持和现有页面一致。完成后运行构建命令验证。
```

### 方式二：Codex CLI

适合程序员和经常在终端工作的用户。进入项目目录后启动 Codex，登录 ChatGPT 或配置 API key，然后让它在当前项目中工作。

新手建议先让 Codex 做三件事：

1. 读项目结构。
2. 给出修改计划。
3. 改完后运行测试或构建。

常用提示词：

```text
先不要改代码，请阅读项目并给我一个实现计划，列出会改哪些文件。
```

```text
按计划实现。改完后运行 pnpm run build，如果失败请继续修复。
```

### 方式三：IDE 插件

适合经常使用 VS Code、Cursor 或 JetBrains 系列工具的人。优势是能在编辑器里直接结合当前文件、代码片段和项目上下文。

适合任务：

- 解释当前函数
- 重构一个组件
- 补单元测试
- 检查类型错误
- 写提交说明

### 方式四：Codex Web / 云端任务

适合把 GitHub 仓库交给 Codex 处理任务。常见流程是连接 GitHub，选择仓库，让 Codex 在云端环境中完成修改并提交 PR。

这种方式适合：

- 修复 GitHub issue
- 做 PR review
- 给开源项目补文档
- 让 Codex 处理较长的开发任务

## 五、让 Codex 更好用的提示词写法

Codex 很适合明确任务，不适合一句“帮我优化一下”就期待完美结果。建议每次给它四类信息：

| 信息 | 示例 |
|---|---|
| 背景 | 这是一个 VuePress 中文内容站 |
| 目标 | 新增一篇面向 Bing 搜索的 Codex 教程 |
| 约束 | 不要破坏现有 permalink；不要引用不存在的图片 |
| 验证 | 完成后运行 pnpm run docs:build |

更好的提示词示例：

```text
请新增一篇中文 SEO 文章，关键词是“codex怎么用”和“codex是什么”。文章要包含新手准备 ChatGPT 账号、Google 邮箱、Plus 订阅、Codex 登录和使用流程。完成后把文章加入目录页和结构化 FAQ，并运行构建验证。
```

## 六、如何长期稳定拥有自己的 ChatGPT 账号？

“永久拥有”不是平台能承诺的事，因为账号规则、地区政策、支付风控和产品计划都会变化。更现实的目标是：**长期稳定、可恢复、归自己控制。**

建议按这个清单做：

- 邮箱归自己所有，不使用共享邮箱
- 手机号或 eSIM 能长期保留
- 支付方式归自己控制
- 开启多因素验证
- 保存恢复代码
- 不使用来路不明的代充、共享号和接码号
- 不在陌生设备上长期保持登录
- 定期检查 ChatGPT、Google 和 GitHub 的登录设备
- 订阅 Plus 或 Pro 时，优先使用官方入口

如果你的目标是流畅使用 Codex，网络稳定性也很重要。可以参考本站的 [2026稳定机场推荐与 ChatGPT 网络测试方法](/posts/jichang-tuijian/)，先用短周期套餐测试 ChatGPT 连续对话、Codex 登录、GitHub 访问和开发文档访问是否稳定。

## 七、常见问题 FAQ

### Codex是什么？

Codex 是 OpenAI 的 AI 编程 agent，可以帮助用户写代码、改代码、审查代码、解释项目、运行命令和完成开发任务。

### Codex怎么用？

准备好 ChatGPT 账号后，可以通过 Codex App、Codex CLI、IDE 插件或 Codex Web 使用。新手建议先让 Codex 阅读项目结构，再给出计划，最后执行修改和构建验证。

### Codex一定要 ChatGPT Plus 吗？

不一定。OpenAI 帮助中心显示 Codex 已包含在多个 ChatGPT 计划中，但不同计划额度不同。如果想更流畅地持续写代码，Plus 或更高计划通常更合适。

### 使用 Codex 一定需要国外手机号吗？

不一定。是否需要手机号、短信或 WhatsApp 验证取决于 ChatGPT 当时的注册和安全验证提示。长期使用建议准备一个自己能保留和恢复的号码，避免一次性接码平台。

### 可以购买 Google 账号或 ChatGPT 账号吗？

不建议购买来路不明账号。账号可能被找回、封禁或泄露隐私，也可能违反平台规则。更稳妥的方式是自己注册邮箱和 ChatGPT 账号，并绑定自己的恢复方式。

### Codex和ChatGPT有什么区别？

ChatGPT 更偏通用问答和内容助手；Codex 更偏软件开发任务，能围绕代码仓库读文件、改文件、运行命令和验证结果。

## 总结

Codex 的核心价值，是把 ChatGPT 从“回答问题”推进到“参与开发”。它能帮你读项目、写代码、改 bug、跑验证和整理提交说明。

真正影响体验的不是某个一次性技巧，而是一套稳定基础：自己的 Google 邮箱、自己的 ChatGPT 账号、可恢复的手机号或 eSIM、合适的 Plus/Pro/API 方案，以及稳定网络环境。把这些准备好，再去使用 Codex，体验会顺很多。
