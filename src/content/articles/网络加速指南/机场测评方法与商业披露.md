## 为什么单独说明测试与披露

机场推荐类内容很容易出现两个问题：一是只放测速截图，不说明测试环境；二是只放购买链接，不说明推广关系。这样读者很难判断内容能不能参考。

本站把测试说明和商业披露单独成文，是为了让核心推荐页保持可读，同时把测试口径、复核规则、推广关系和风险边界讲清楚。核心页会保留简短说明，详细内容统一指向本页。

## 测试说明

机场体验受地区、运营商、设备、套餐、节点负载、客户端版本和平台风控影响。本站不会把一次测试写成永久结论，也不会承诺某个机场在所有地区都稳定。

| 测试维度 | 观察内容 | 为什么重要 |
|---|---|---|
| 测试时间 | 优先观察 20:00-23:00 晚高峰 | 白天可用不代表晚上稳定 |
| 连接成功率 | 客户端启动、节点连接、断线重连 | 新手最容易卡在连接阶段 |
| ChatGPT | 连续对话 10-20 分钟 | 判断是否频繁网络错误或中断 |
| YouTube | 1080P 或 4K 播放体验 | 判断视频缓冲、画质和稳定性 |
| 通用订阅 | Clash、Shadowrocket、Stash 导入 | 判断多端兼容和订阅更新 |
| 专属客户端 | 安装、登录、切换节点、长连接 | 判断新手使用门槛 |
| 售后与公告 | 工单、公告、备用入口、故障说明 | 判断维护能力和失联风险 |
| 购买风险 | 试用、月付、不限时、年付规则 | 降低第一次下单踩坑概率 |

## 页面复核和实测的区别

本站会把“页面复核”和“晚高峰实测”分开写。

| 类型 | 含义 | 能说明什么 | 不能说明什么 |
|---|---|---|---|
| 页面复核 | 检查页面结构、入口、套餐字段、链接标注和风险提示 | 页面信息是否需要修正 | 不能等同于重新测速 |
| 晚高峰实测 | 在指定时间段观察连接、视频、AI 工具和客户端表现 | 某个时间点的真实体验 | 不能代表所有地区和长期稳定 |
| 长期观察 | 多次记录官网、公告、售后和节点变化 | 更接近长期可用性判断 | 仍不能保证未来不波动 |

如果一篇文章只更新了页面结构，而没有重新测速，本站会尽量写清楚“最近复核”和“最近实测”的区别。

## 商业披露

本站部分机场页面包含推广链接、邀请码、优惠码或带参数的注册链接。读者通过这些链接注册或购买时，本站可能获得推广收益。

推广关系不改变以下规则：

1. 有推广关系的链接会使用 `rel="sponsored nofollow noopener"`。
2. 页面仍会保留风险提示、短周期测试建议和不适合人群。
3. 不会把“有推广关系”写成“永久稳定”或“所有人都适合”。
4. 套餐、价格、节点、客户端、试用和退款规则以下单前官网页面为准。
5. 如果入口异常、公告异常、售后失联或争议明显，会优先提示风险。

## 推荐顺序怎么判断

机场推荐不是只看佣金、价格或节点数量。本站更看重读者能不能快速判断自己是否适合。

| 判断项 | 优先级 | 说明 |
|---|---|---|
| 新手易用性 | 高 | 第一次使用时，能否顺利安装、登录和连接很重要 |
| 晚高峰稳定 | 高 | 20:00-23:00 是很多用户最容易遇到拥堵的时间段 |
| 核心场景 | 高 | ChatGPT、YouTube、流媒体、资料查询和远程办公需求不同 |
| 短周期测试 | 高 | 第一次不建议直接长期续费 |
| 通用订阅 | 中 | 会用 Clash、Shadowrocket、Stash 的用户更需要关注 |
| 低价套餐 | 中 | 低价适合备用，但通常需要接受线路、带宽或售后的取舍 |
| 优惠码 | 低 | 优惠码只能降低成本，不能证明长期稳定 |

## 哪些结论不能过度理解

机场服务具有时效性，以下情况都不适合被理解成永久承诺：

- 某次测速截图。
- 某个节点一段时间内可用。
- 某个平台一次成功解锁。
- 某个入口当前能打开。
- 某个客服通道短期能响应。
- 某个套餐当前价格较低。

更稳的做法是把推荐页当作候选清单，把测试页当作方法说明，再用自己的设备、地区、运营商和常用时间段做短周期验证。

## 更新规则

本站后续更新机场推荐内容时，会优先处理这些变化：

1. 官网入口、注册链接或备用入口明显异常。
2. 套餐价格、月流量、试用规则或不限时套餐变化。
3. 专属客户端、通用订阅或协议兼容发生变化。
4. 晚高峰体验和 ChatGPT、YouTube 等核心场景表现明显变化。
5. 出现售后失联、公告长期不更新、争议集中或疑似跑路风险。

如果只是页面排版、内链或表格字段调整，会标注为页面复核；如果重新测试了连接、视频或 AI 工具，会标注具体测试时间。

## 常见问题

### 有推广链接的机场还能推荐吗？

可以，但必须清楚标注推广关系，并保留风险提示、短周期测试建议和不适合人群。推广关系不能替代真实测试和读者自己的判断。

### 页面复核等于重新测速吗？

不等于。页面复核主要检查信息是否需要修正，重新测速才代表在某个时间段重新观察连接、视频、AI 工具和客户端表现。

### 为什么不直接给永久排名？

机场服务会受线路、节点、入口、平台风控和用户数量影响，永久排名容易误导读者。更稳的方式是按场景筛选，再短周期测试。
