## 风险说明

本站风险监测不是自动化实时探测，也不承诺预测机场跑路。这个页面记录的是内容复核时发现的观察点，帮助读者在购买前多做一步检查。

机场服务具有明显时效性。官网入口、套餐、节点、客户端、订阅规则、支付方式和客服响应都可能变化。任何推荐都不应替代你自己的短周期测试。

## 风险等级说明

| 等级 | 含义 |
|---|---|
| 正常观察 | 当前页面信息未发现明确高风险，但仍需短周期测试 |
| 规则观察 | 套餐、订阅、客户端或入口规则存在需要下单前确认的点 |
| 低价观察 | 低价或大流量套餐可能在稳定性、客服或冗余上有取舍 |
| 小众观察 | 更适合作为备用候选，需要关注维护频率和公告 |
| 资料观察 | 现有资料不足以支持价格、功能或性能结论 |
| 历史资料观察 | 有旧套餐或功能记录，但不能当作当前官网状态 |
| 归属观察 | 有测试图片，但图片无法独立确认对应服务 |
| 高风险 | 出现官网长期异常、客服失联、订阅无法使用或大量负面反馈时才列入 |

## 续费前 5 分钟检查

| 步骤 | 检查内容 |
|---|---|
| 1 | 打开官网和备用入口，确认能正常登录 |
| 2 | 查看公告、工单、客服和套餐是否近期变更 |
| 3 | 更新订阅并测试常用节点 |
| 4 | 晚高峰测试 ChatGPT、YouTube、Google、GitHub |
| 5 | 确认支付方式、退款规则和套餐周期，再决定是否续费 |

## 跑路征兆速查

出现下面情况时，建议暂停长期续费：

- 官网、订阅地址或客服长期不可用。
- 套餐价格突然大幅变化且没有清楚说明。
- 公告长期不更新，工单无人回复。
- 节点大面积不可用，且没有维护说明。
- 频繁更换域名、入口或支付方式。
- 社群中出现大量相似投诉，但官方没有解释。

## 常见问题

### 风险监测页是不是实时监控？

不是。本站当前是人工复核和内容维护口径，不冒充实时监测平台。页面只记录购买前应该注意的风险点。

### 正常观察是不是一定安全？

不是。正常观察只表示页面复核时没有列入高风险，机场服务仍可能因为线路、入口、节点和平台风控发生变化。

### 低价观察是不是不推荐购买？

不是。低价服务可以测试，但更适合短周期、轻度使用或备用线路，不建议第一次直接长期续费。

### 续费前最重要的检查是什么？

先确认官网和订阅能正常使用，再在自己的常用时间段测试 ChatGPT、YouTube、Google、GitHub 和常用节点。
